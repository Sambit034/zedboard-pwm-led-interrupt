  • PWM IP: a counter runs to PERIOD (100000 clocks at 100 MHz, 1 kHz). Each channel is high while the counter is below duty × PERIOD / 256, and fully on at duty 255.
  • Mode 0, manual: the main loop reads the switches (0–255), writes DUTY_LO and DUTY_HI, and prints the status line.
  • Mode 1, breathing: the main loop ramps the duty up and down in 4 ms steps with a squared curve.
  • BTNC interrupt: the ISR runs on every button edge. It toggles the mode on a press only when the button has been quiet for 100 ms, so bounce spikes are ignored.
  • Display: LED glow uses a perceptual curve so low duty values stay visible. The waveform and percentages are exact.

Each clock is 10 ns (100 MHz). The threshold is rounded down, which is why 1/256 steps never add up to more than a 0.4 % error.

The real counter takes 100000 steps per period, far too fast to see. Here one period is drawn as 64 steps (threshold = d × 64 / 256) so you can follow the counter, the comparison and the output pin tick by tick. It follows the current LD0 duty.
